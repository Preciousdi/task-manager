
# Stage 3 – API Integration

## What I Did
I connected my React Task Management App to the JSONPlaceholder API.

## What I Implemented
- GET – Fetch tasks.
- POST – Add new tasks.
- PATCH – Update tasks.
- DELETE – Remove tasks.
- Loading message.
- Error message.
- Refresh tasks button.

## What I Learned
- How to use the Fetch API.
- How to use async and await.
- How to handle errors with try and catch.
- How to use useEffect and useState.
- How to connect React to an external API.

## API Used
https://jsonplaceholder.typicode.com/

## Note
JSONPlaceholder is a testing API. Changes are not permanently saved.
